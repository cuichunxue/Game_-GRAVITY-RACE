# GRAVITY RACE 試作 v0.3

`index.html` をブラウザで開くと遊べます。ゴーストリンクと共有画像を試すときは、ローカルサーバーから開いてください（例：`npx http-server .`）。`file://` で開くとブラウザが画像の書き出しを止めるため、共有はテキストだけになります。

企画書 Ver.2.0 と素材リストをもとに、v0.2（`GRAVITY RACE.html`）を作り直した版です。v0.2 と旧MVP（`gravity-race-mvp.zip`）は比較用にそのまま残しています。

## v0.2 からの変更

### 素材リストのMVP素材を組み込み
| ID | 内容 | ファイル |
| --- | --- | --- |
| I-01 | アプリアイコン：最速降下曲線、直線の点線、鉄球 | `assets/icon.svg`、`icon-1024/512/192.png`、`apple-touch-icon.png` |
| I-02 | ロゴ（横組・正方形） | `assets/logo.svg`、`assets/logo-square.svg` |
| I-03 | 共有カードの台紙。タイムと比較はコードで描き込む | `assets/share-card.png`（OGP画像も兼用） |
| I-04 | 指ガイド。初回だけ表示し、ピンを動かしたら消える | `assets/finger-guide.svg` |
| I-05 | UIアイコン9点（24px、線幅2px） | `index.html` 内のSVGスプライト |
| S-01〜S-20 | 効果音20種。すべてWeb Audioで合成するため、音声ファイルは0バイト | `src/sfx.js` |

- 転がり音は速度に合わせてピッチと音量が変わります。ボールの種類で音色が変わり、秒速5m以上では風切り音が加わります。
- スタート時に 3・2・1 とベルが鳴ります。ほかにジャンプ、着地（強さ2段階）、スロー突入、ゴール、シャッター、勝ち・惜敗のジングル、コースアウト、失速、ピン操作のクリック、0.1mごとのラチェット音があります。
- 音は初回は消音で始まります。音量ボタンは常に表示し、設定は保存されます。

### 企画書の拡散設計を実装
- **ゴーストリンク**：URLの `#` 以降にピン座標が入ります。リンクを開くと送り主の軌道が紫のゴーストとして並走し、タイムは受け取った側で再計算します。物理は決定論的です。日付の違うデイリーへのリンクは案内を出して無効にします。
- **結果画面の最初のボタンを「挑戦状を送る」に変更**しました（企画書のルール）。スマホでは共有シートで画像・文・リンクをまとめて送ります。PCではコピーし、画像は保存ボタンから保存します。
- 共有の文面は企画書の形式に合わせました：`GRAVITY RACE #127 2.43秒 / 3回中1回目 · 世界ゴースト比 +0.21秒`
- デイリーは練習ステージを全部クリアしなくても遊べるようにしました。リンクから直接デイリーに入れるようにするためです。

### 最適化
- 編集画面は、ピンを動かしたときなど変化があったときだけ再描画します。v0.2 は毎フレーム物理計算と全軌道の構築をやり直していました。
- 色の読み込み（`getComputedStyle`）は、毎フレームではなく起動時とテーマ変更時だけ行います。
- 色の計算をHEXの数値処理に置き換え、セグメントごとの正規表現をなくしました。あわせて、半透明のレーンが灰色になる不具合を直しました。
- ボール位置の検索を二分探索にし、地面グリッドの描画を1回のパスにまとめました。
- `<head>` を正しい構造に直し、`lang="ja"`、OGP、manifest、theme-color を追加しました。
- 初回の読み込みは約75KB（フォントを除く）で、上限の1MBを大きく下回ります。共有カードの画像は結果画面で初めて読み込みます。

## ファイル
- `index.html`：画面とスタイル
- `src/game.js`：物理、描画、レース、共有
- `src/sfx.js`：合成効果音
- `assets/`：画像素材
- `tools/build-assets.mjs`：SVG素材の生成とPNGの書き出し（`node tools/build-assets.mjs`、Playwrightが必要）

## 公開時の注意
- `og:image` は相対パスです。公開URLが決まったら絶対URLに書き換えてください。
- ロゴとアイコンは仮版です。素材リストでは「デザイナー」担当の項目なので、仕上げを依頼する前提です。
